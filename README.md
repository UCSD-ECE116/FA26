# ECE 116 · Fall 2026

Released student materials for UC San Diego ECE 116: Advanced Hardware and Software Design.

## Start in Canvas

Use the [Canvas course](https://canvas.ucsd.edu/courses/78439) for the syllabus and quarter schedule, meeting links, announcements, assignment submissions, and grades. Submit A1-A4 as one complete ZIP each and the final project as a report PDF, MP4 video, and supporting trial-data ZIP; do not upload student work to this public repository.

## Material release schedule

Lecture slides are released seven days before the lecture. Assignment handouts and starter packages are released seven days before the assigned/start date. Files appear here only after release review and approval. A missing future file is not an instruction to locate another branch or an instructor solution.

The Canvas syllabus defines the automatic grace period, late deduction, and Monday hard close. A1-A4 each contribute 18.75% of the course grade, and the final project contributes 25%. There is no participation grade or proposal.

Lectures use L00-L16. L16 is the short November 17 final-project introduction. November 24,
December 1, and December 3 are project work. The final brief is visible from the start of the
quarter. The final is due December 4 at 7 p.m. Pacific and closes December 7 at 7 p.m.
Submit a PDF with four technical pages plus one AI-use page and one reference page, a 3-5 minute
MP4 video, and a trial-data ZIP through Canvas. The generic two-column Word template supplies
formatting only. Coding support is encouraged. The classifier has at least two target classes
plus other/background, with measured timing/gating decisions and model-failure analysis.

## Repository boundary

This repository contains only released course materials. Student submissions, grades, credentials, future teaching files, and instructor solutions do not belong here. Report missing or incorrect links to course staff through Canvas.
